# design-review: requirements v1.2(リバース追記)

- 対象: docs/design/requirements.md(v1.1 = 204行 → v1.2 = 491行)
- 実施日: 2026-08-09
- 方式: 2レンズ(arch / data)× 2ラウンド。**R1 両レンズ FAIL → R2 両レンズ PASS**
- 性質: 新規設計ではなく**実装からの逆写し**。したがって判定基準は「妥当か」ではなく
  **「現物と一致しているか」**。事実誤りは1件でも FAIL 扱いとした。

## R1 — 両レンズ FAIL(逆写しなのに事実誤りを多数持ち込んだ)

| # | 誤った記述 | 現物 |
|---|---|---|
| 1 | `timeline_records.type` が7値 | **8値**(`knowledge` は 0004 で追加済み)。同じ v1.2 の §3-12 が「knowledge 型として取り込み」と書いており**自己矛盾**していた |
| 2 | 取込目録に `.session-summaries` / `.conversation-log` / `board.md` / `docs/templates` | **1つも取り込んでいない**。逆に組織 docs 8パスが未記載。判定の正典は実装の allowlist(run-sync.ts) |
| 3 | 整理ループの書き戻し先は ai-war-room のみ | **2 repo**(同じ文書の §6・§9 は2 repo と書いていた) |
| 4 | `review_bot` は「状態列のみ」書ける | **`result`(最大30000字)も書ける** — 被害上限の過小申告 |
| 5 | Cron は毎時 | **日1回**(JST 06:00) |
| 6 | front-check は「スクショをすべて無効化」 | **証跡用の明示スクショは撮る**。この誤記だと「画像を repo/PR/チャットに出すな」という禁止事項の存在理由が消える |
| 7 | organize-loop は「有効化待ち」 | **ユーザー操作だけでは有効化できない**(OIDC・`Write(out/**)` の2欠陥。別 goal + 3レンズ再通過が要る) |

| 9 | 「AI 4経路の共通原則」 | **SPAR だけ**が結論を capture に保存する。他3経路は読取・保存なし |
| 10 | `timeline_records` / `sync_state` の列挙が不完全 | `item_key` / `status` / `synced_at` / `embedding_model` / `embedded_at`、`last_summary` / `progress` が欠落 |

**最も重い指摘 = §11 の受け入れ条件が自己参照 grep だった。** 「本書が実装と乖離していないこと」を
判定するはずの条件の**母集団が requirements.md 自身**で、本文が言及している限り必ず PASS する。
上の10件を**1件も検出できない**(検出力ゼロの条件は、無いより悪い — 緑を根拠に読まれるため)。

## R2 で入れた構造的な直し

母集団を**実装側の成果物**に反転した(本書の外に置く):

| 条件 | 母集団 |
|---|---|
| CI workflow の網羅 | `.github/workflows/*.yml` |
| テーブルの網羅 | `db/migrations/*.up.sql` の `CREATE TABLE IF NOT EXISTS` |
| CI ロールの網羅 | `docs/setup/organize-role.sql` の `CREATE ROLE` |
| `type` 語彙の一致 | 0004 の CHECK |
| 設計書の網羅 | `docs/design/basic/*.md` |

反転した直後に**実在の乖離9件(workflow 3件・設計書6件)を実際に検出**した。条件が機能する
ようになった証拠として記録する。

同時に**保証範囲の限界を §11 に明記**した(両レンズの共通の問い): これらが保証するのは
**「網羅」だけで「記述の正しさ」ではない**。R1 の事実誤りはすべて「名前は出ているが中身が誤り」の
クラスで、新条件でも1件も捕まらない。**この層の防御は design-review(3レンズの現物照合)だけ**である、と
本文に書いた。「§11 が全緑 = 実装と一致」と次の改訂者に読ませないため。

## R2 — 両レンズ PASS + 残指摘10件(すべて反映済み)
